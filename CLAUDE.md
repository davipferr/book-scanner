## Pipeline de skills no Claude Code

- As skills ficam em `.claude/skills/` depois do `npm --prefix pipeline run setup`. Chame-as pela ferramenta Skill (ex.: `run-pipeline`); o usuário também pode digitar `/run-pipeline`.
- As etapas `grill` e `implement` são interativas: faça as perguntas e espere a resposta do usuário.
