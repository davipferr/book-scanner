# Ideia: Contador de palavras

## Problema
Quando escrevo textos para a faculdade, preciso saber quantas palavras tenho e quais estou repetindo demais. Hoje colo o texto num site diferente a cada vez.

## Ideia
Um comando de terminal: passo um arquivo e ele mostra quantas palavras, linhas e caracteres tem, e quais palavras aparecem mais.

## Para quem
Para mim, rodando no meu computador.

## Restrições já conhecidas
- Precisa funcionar com texto em português (acentos).

## Em aberto
- Linguagem?
- Aceitar texto colado (stdin) ou só arquivo?
- "Casa" e "casa" são a mesma palavra?
