# Book Scanner

Scan the pages of a book you own with your phone camera, turn them into searchable text, and study them, all in the browser. It's a static site hosted for free on GitHub Pages, with no server and no account. Pages never leave your device.

## Run locally

```bash
npm install
npm run dev
```

The camera only works on `https://` or `localhost`. Opening the dev server on a phone through `http://192.168.x.x:5173` blocks the camera. Use the deployed GitHub Pages URL to test on the phone (the "Take or choose photos" fallback still works over HTTP).

## Text reading (OCR)

The Tesseract.js worker and engine are served from this site (copied from `node_modules` at build time, under versioned paths); the language data comes from jsDelivr. All of it downloads the first time you read a page and is then cached, so reading text needs an internet connection only that first time.

## Offline and install

`build/pwa.ts` is a small Vite plugin that writes `sw.js` from `build/service-worker.js`, filling in the list of built files to precache and a version hash of their contents. Any change to the app gives a new version: the open app shows "A new version is ready" and switches over when you tap Update. The service worker only runs in production builds (`npm run build && npm run preview`), not in `npm run dev`.

Icons are generated by `python scripts/make-icons.py` (needs Pillow) into `public/icons`.

## Deploy (GitHub Pages)

1. Push to a GitHub repo named `book-scanner`.
2. In **Settings → Pages**, set **Source** to **GitHub Actions**.
3. Every push to `main` runs `.github/workflows/ci.yml` (tests, type check, build, deploy) and publishes to `https://<user>.github.io/book-scanner/`.
